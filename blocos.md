1. Bloco de Definição do Nó (struct No)
O que faz em C: Define a estrutura de dados base da lista. Cada nó armazena um número inteiro (valor) e um ponteiro apontando para o próximo elemento (proximo).
O mapeamento para Assembly: Em C, o compilador calcula o tamanho da estrutura automaticamente. Para o Assembly, o grupo precisou internalizar que cada "Nó" ocupará exatamente 8 bytes na memória. Os primeiros 4 bytes (offset 0) são dedicados ao valor inteiro, e os 4 bytes subsequentes (offset 4) armazenarão o endereço de memória do próximo nó.
2. Bloco de Alocação (aloca_no)
O que faz em C: Isola a chamada da função malloc(), solicitando ao sistema operacional a reserva de espaço na memória para um novo nó e retornando o endereço desse espaço.
O mapeamento para Assembly (Requisito do Heap): Este bloco foi desenhado para simular o comportamento da alocação dinâmica exigida no trabalho. No RISC-V, isso será traduzido para a preparação dos registradores e a execução de uma syscall (especificamente a chamada sbrk, código 9 em simuladores como RARS/Venus). O grupo entende que a syscall fará o papel do malloc, devolvendo em um registrador (como o a0) o endereço base do novo bloco de 8 bytes no heap.  
3. Bloco de Inserção (insere_lista)
O que faz em C: Recebe o endereço da cabeça da lista e o novo valor. Ele chama a função de alocação, preenche o novo nó com os dados, faz o ponteiro deste novo nó apontar para a antiga cabeça da lista e, por fim, atualiza a cabeça para ser o novo nó. A inserção ocorre no início da lista (complexidade O(1)).
O mapeamento para Assembly (Requisito da Pilha): Este é o bloco crítico para a avaliação do professor. Como a função de inserção precisa invocar a função aloca_no, ocorre uma chamada aninhada. Em Assembly, a instrução de salto (jal) para aloca_no sobrescreverá o registrador de endereço de retorno (ra). Portanto, o grupo compreende que será obrigatório manipular o Stack Pointer (sp) no início desta função para salvar o ra na pilha (stack) e restaurá-lo antes de finalizar, evitando que o programa perca o fluxo de execução.  
4. Bloco de Impressão (imprime_lista)
O que faz em C: Utiliza um laço de repetição (while) que percorre a lista nó por nó até encontrar um ponteiro nulo (NULL), imprimindo os valores na tela.
O mapeamento para Assembly: Servirá como a rotina de validação visual do trabalho. O laço while se transformará em um bloco com instruções de desvio condicional (como beqz - branch if equal to zero). Dentro do laço, o grupo fará a leitura da memória (lw) no offset 0 para imprimir o número usando uma syscall de impressão, e depois fará uma leitura no offset 4 para carregar o endereço do próximo nó, reiniciando o ciclo.
5. Bloco Principal (main)
O que faz em C: Inicializa a lista como vazia (NULL) e orquestra as chamadas das funções de inserção e impressão.
O mapeamento para Assembly (Requisito de Saltos): Representa o ponto de entrada do programa. O valor NULL do C será traduzido simplesmente para o valor 0 no registrador que representará a cabeça da lista. Este bloco fará uso intensivo das instruções obrigatórias de salto e ligação (jal) para transferir o controle para as rotinas de inserção e impressão, passando os argumentos necessários via registradores (como a0 e a1).
